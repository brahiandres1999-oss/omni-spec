# OmniSpec 0.5.0

Versión normal de la base 0.5.0 para desarrollo guiado por especificaciones desde agentes y CLI. El repositorio y esta release permanecen privados; npm se publicará por separado cuando el mantenedor configure su cuenta.

## Incluye

- Nueve flujos: reconocer el proyecto, discutir, especificar, aclarar, planificar, organizar tareas, auditar, implementar y converger.
- Runtime local sin dependencias externas y adaptadores específicos por agente; Antigravity es la integración principal.
- Features, bugs, deuda técnica y RFC con artefactos proporcionales al trabajo.
- Cierre condicionado a criterios explícitos en `acceptance.json`, gates revisados y verificación vigente.
- Actualizaciones con vista previa, conservación de trabajos y bloqueo de personalizaciones en conflicto.
- Paquete instalable y checksum SHA-256 tras validar Windows/Ubuntu y cuatro versiones de Node.
- Presentación del README recuperada y documentación de usuario separada de diagnósticos internos retirados del árbol actual.

## Instalar o actualizar

Descargar el `.tgz` y su checksum con una cuenta autorizada. Desde la raíz del proyecto:

```sh
npx --yes --package="/ruta/al/omni-spec-0.5.0.tgz" omni-spec init --yes --agent antigravity
```

Si OmniSpec ya está instalado, usar `update --dry-run` y luego `update` en lugar de `init`. Las copias de desarrollo que ya dicen 0.5.0 también reciben los archivos nuevos sin `--allow-downgrade`. Se conservan contexto, constitución y especificaciones, incluidos trabajos completados. Recargar el agente después.

Las especificaciones antiguas no se migran inventando evidencia: solo al volver a verificarlas se deben incorporar sus criterios y `acceptance.json`.

El paquete no certifica todos los hosts/modelos ni elimina las alucinaciones. La generación de adaptadores y los recorridos automatizados se distinguen del chat real. Ver [compatibilidad y límites](../COMPATIBILITY.md) y [actualización](../RELEASING.md).
