# OmniSpec 0.6.1

Versión de refinamiento arquitectónico y experiencia de desarrollo limpia (*Zero Project Bloat*). Introduce el gestor nativo de plugins para Google Antigravity y desacopla el motor CLI de los repositorios de usuario.

## Novedades y Mejoras

- **Gestor Nativo de Plugins para Antigravity (`omni-spec plugin`):**
  - Comando `npx omni-spec plugin install` para desplegar el plugin limpio (~180 KB) directamente en `~/.gemini/config/plugins/omni-spec/` en menos de 100 ms.
  - Elimina la necesidad de clonar repositorios completos con Git (`git clone`), evitando la descarga innecesaria del historial `.git/`, suites de prueba y scripts de desarrollo.
  - Comando `npx omni-spec plugin update` para mantener el plugin sincronizado con el registro de npm.
  - Comando `npx omni-spec plugin status` para auditar la presencia y versión del plugin instalado.

- **Modo Proyecto Limpio (*Zero-Bloat Project Mode*):**
  - Soporte para `"agent": "plugin"` en `specs/manifest.json`.
  - Los proyectos que usan el plugin global ya no requieren almacenar 60 archivos de código de runtime en `specs/.omni/runtime/` ni carpetas `.agents/skills/`.
  - El repositorio de usuario queda 100% ligero, albergando únicamente sus especificaciones vivas (`specs/`) y su constitución (`CONSTITUTION.md`).

- **Comando de Limpieza y Migración Segura (`omni-spec clean`):**
  - Comando `npx omni-spec clean [--dry-run]` que analiza el workspace y elimina de forma segura `.agents/skills` y `specs/.omni/runtime/` sin alterar ninguna especificación, tarea ni regla de negocio.
  - Actualiza el manifiesto a `agent: "plugin"` y garantiza que `omni-spec doctor` reporte estado sincronizado y saludable.

- **Resolución Dinámica del CLI en las 9 Skills:**
  - Las 9 habilidades oficiales (`omni-init`, `omni-plan`, `omni-specify`, etc.) ahora resuelven el motor ejecutable en orden jerárquico: CLI del Plugin Global -> CLI Local (si existe por legado) -> `npx omni-spec`.

## Guía de Migración

Para migrar cualquier proyecto existente al modo limpio con plugin global:

```bash
# 1. Instalar el plugin global en Antigravity
npx omni-spec plugin install

# 2. Limpiar el proyecto eliminando el runtime viejo
npx omni-spec clean
```
