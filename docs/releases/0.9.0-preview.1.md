# OmniSpec 0.9.0-preview.1 — Omni Studio, memoria nativa y cartografía

**Preview local, sin publicar.** No está en npm ni en GitHub Releases. Se instala desde el tarball y el instalador generados en esta máquina. La versión publicada sigue siendo `0.8.1` (npm `latest`).

Esta Preview congela, con un número, todo el trabajo hecho desde `0.8.1`: las fases 1 a 4 de Next-Gen y las vueltas 1 a 7 del cockpit de agentes de Omni Studio. Sirve para usar OmniSpec en tus proyectos y para volver a este punto exacto cuando haga falta. No es una versión terminada: la sección de limitaciones dice qué falta.

---

## Qué es cada pieza

| Pieza | Qué es | Archivo de esta Preview |
|---|---|---|
| **Motor / CLI** | `omni-spec`: el CLI, las skills, la memoria, el servidor MCP, la cartografía y el motor de Studio (`src/studio/`) | `artifacts/release/omni-spec-0.9.0-preview.1.tgz` (más su `.sha256`) |
| **Omni Studio** | La app de escritorio para Windows. Lleva **dentro una copia del motor de esta misma versión** | `artifacts/release/Omni Studio_0.9.0-preview.1_x64-setup.exe` |

Las dos piezas comparten número de versión. El motor que usa Studio es el mismo código que va en el tarball. Las carpetas `artifacts/` no se versionan en Git: si se borran, se vuelven a generar desde el tag `v0.9.0-preview.1` con `npm run release:pack` y `npm run tauri build` (en `apps/studio`).

## Novedades

### Omni Studio (nuevo)
- Cockpit de chat para los agentes que ya usas, cada uno con su propio inicio de sesión: **Claude Code**, **Codex**, **OpenCode** y **Cline** (por ACP). **Antigravity** es experimental y viene apagado.
- Varias conversaciones en paralelo, por proyecto, con avisos, coste por turno, medidor de contexto, menú de modelo y esfuerzo, permisos y cola de mensajes.
- Los agentes pueden **preguntarte** con un panel nativo en el chat (`omni_ask_user`).
- Reanudar en Studio sesiones de Claude y Codex empezadas en la terminal.
- Borrar una conversación: el historial del agente va a la Papelera de reciclaje (se puede recuperar).
- Memoria de OmniSpec compartida con cada agente por MCP, sin escribir archivos de configuración en tu proyecto.

### Motor
- **Memoria v4:** SQLite nativo con observaciones, decisiones y sincronización con Git.
- **Servidor MCP:** `omni-spec mcp` (y `--studio`).
- **Gobernanza:** guardian sin shell, circuit breaker, verificación firmada con HMAC y broker de autenticación con DPAPI.
- **Cartografía:** `omni-spec cartography` y `omni-spec blast-radius <archivos>` (grafo de módulos e impacto de un cambio).
- **Ceremonia proporcional** y endurecimiento de `fit`, `configure`, `audit` y `verify` (specs 025–033).

El detalle completo está en el [CHANGELOG](../../CHANGELOG.md#090-preview1--2026-11-08).

## Usarla en un proyecto

### Motor (cualquier herramienta: Claude Code, Codex, Cursor, Antigravity…)

En PowerShell, desde la carpeta del proyecto:

```powershell
$omni = 'C:\dev\Analisis propio OMNI\omni-spec\artifacts\release\omni-spec-0.9.0-preview.1.tgz'
npm exec --offline --yes --package "$omni" -- omni-spec init --agent claude
node specs/.omni/runtime/bin/omni-spec.mjs version   # debe decir 0.9.0-preview.1
```

Cambia `--agent claude` por tu herramienta. Si el proyecto ya tiene OmniSpec 0.8.x, actualiza en lugar de reinstalar:

```powershell
npm exec --offline --yes --package "$omni" -- omni-spec update --dry-run
npm exec --offline --yes --package "$omni" -- omni-spec update
```

Si prefieres el comando `omni-spec` en todas partes: `npm install --global "$omni"`. Para volver a la versión publicada: `npm install --global omni-spec@latest`.

### Omni Studio

1. Ejecuta `Omni Studio_0.9.0-preview.1_x64-setup.exe`. No está firmado, así que Windows SmartScreen mostrará un aviso: "Más información" → "Ejecutar de todas formas".
2. Necesitas **Node.js ≥ 22.19** en el `PATH`. El instalador no lo incluye.
3. Cada agente se usa con su propia sesión: inicia sesión antes en su CLI (`claude`, `codex login`, etc.).

## Limitaciones conocidas

**Pruebas**
- Motor: 1022 pruebas pasan. Falla EN-10: `project.snapshot` tarda unos 310 ms en esta máquina y el límite es 150 ms.
- Studio: las 124 de Vitest pasan. Los E2E de Playwright siguen recorriendo el dashboard antiguo; no hay E2E del chat.
- Los turnos con un modelo real solo se han probado a mano.

**Studio**
- Instalador sin firma de código y sin auto-actualización. Node.js no va incluido.
- Las pantallas Uso, Specs y Revisión › Impacto vienen del dashboard antiguo y no están rediseñadas.
- No se comprueba si hay sesión iniciada en un agente hasta que da error (`AUTH_REQUIRED`).
- Antigravity es experimental: no está confirmado que acepte el MCP de Omni. OpenCode, Cline y Antigravity no aparecen en "Retomar sesión".
- La interfaz solo está en español. El dictado por voz de las preguntas todavía no existe.

**Decisiones de producto abiertas**
- Borrar una conversación manda a la Papelera el historial del propio agente. Esto contradice la regla "Studio nunca borra el historial de un agente" de `docs/STUDIO-AGENT-COCKPIT.md`.
- `init --agent studio` escribe cuatro archivos en el proyecto (`CONSTITUTION.md`, `specs/project-context.md`, el manifiesto y `specs/.gitignore`), frente a la visión de "cero archivos".

**Motor**
- La cartografía no llega a sus objetivos de rendimiento (lexer 1,87 M LOC/s de 3 M; indexado en frío 4,5 s de 0,2 s; 89,6 MB de 60).
- `--agent studio` no aparece en `omni-spec --help`.

**Documentación**
- `INSTALLATION`, `ONBOARDING`, `COMPATIBILITY`, `PILOT`, `ROADMAP` y `RELEASING` siguen describiendo 0.8.1.
- Todavía no hay una guía de usuario de Studio.
- El inventario completo está en [`docs/INVENTARIO-0.9.0-preview.1.md`](../INVENTARIO-0.9.0-preview.1.md).
