# OmniSpec 0.7.0-preview.2 — 0.7.0 Preview

**Preparada para lanzamiento; publicación pendiente.** Canal npm `preview`; GitHub prerelease. `latest` conserva 0.6.1. El tag anterior `v0.7.0-preview.1` se conserva: sus tests fallaron antes del empaquetado, por lo que no publicó un paquete npm ni un prerelease.

## Corrección respecto al primer tag

`a**/b` solo ignora `a/b` y `ax/b`; `a/x/b` permanece en la huella de verificación. El segmento completo `a/**/b` sí atraviesa directorios. Se añade una regresión independiente de Git. La comparación diferencial reconoce únicamente el resultado antiguo concreto de algunas compilaciones de Git y sigue exigiendo la semántica documentada de OmniSpec.

El resto del alcance, el instalador, las integraciones, los journeys y los límites corresponden a las [notas de Preview 1](0.7.0-preview.1.md). Esas notas conservan sus comprobaciones históricas; la nueva validación se registra a continuación.
