# Enrutador de diseño: Better Skills

Este recurso acompaña las fases de planificación e implementación de interfaz en OmniSpec.

> [!IMPORTANT]
> **Precedencia constitucional (014-d4):** La Constitución de OmniSpec y `guide design` prevalecen sobre las heurísticas del companion. Cada estado se revisa o se marca N/A con motivo; no se crean estados obligatorios. Las guías no autorizan código defensivo que oculte errores. Las menciones a slash commands, otras skills o comandos de upstream no implican que estén instalados: OmniSpec consulta únicamente el material empaquetado que corresponda a la tarea.
