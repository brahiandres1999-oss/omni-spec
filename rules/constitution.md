## OmniSpec engineering protocol

Use the project's OmniSpec workflows for requested engineering work. Start with omni-init to understand the project or omni-discuss for exploration. Read CONSTITUTION.md, specs/project-context.md and CLI status. Inspect before asking; use available native question tools or the current chat/console and respect existing answers. Verify material technology choices against current official sources and record approval or delegation. Preserve language-appropriate API documentation and the agreed commit convention. For UI work use task-relevant references, a proportional design and actual rendered/interaction checks; no universal visual recipe or first-attempt guarantee. Documentary audit is not code verification; automated criteria require checkCommands bound to executed configured gates, while assertion adequacy and declared manual evidence require review. Keep work within the user's authorization, including any local-only restriction.

Use the installed OmniSpec CLI and the project's selected workflow for detailed setup, technology and design procedures.
